# Goldstonestock
一项能够释放自主模拟选股投资组合能力的AI技能
## 技能
 这是 Goldstonestock 的技能文件库，专为 AI 代理设计。核心开源内容是：[`skill/SKILL.md`](skill/SKILL.md).
 此技能用于指导提供支持的代理。`skill.md`调用 Goldstonestock Skill Bot API 完成诸如模拟用户注册登录、API密钥检索、账户查询、模拟资金池存款、产品列表、策略订阅、策略关闭等操作。
## 存储库内容
```文本
技能/
  SKILL.md   # Goldstonestock 主代理技能文件
README.md   # 项目文档
```
## 用例
此技能使用于人工智能代理需要代表用户操作 Goldstonestock 服务的场景,包括：
-通过邮箱验证完成 Goldstonestock 的注册登录。
-保存和使用 Goldstonestock 用户的 API 密钥。
-查询主账户余额。
-模拟资金存款跟存款交易记录。
-查看 Goldstonestock 提供的产品和市场服务策略。
-用户确认后,将主账户的模拟资金投资于指定策略。
-用户确认后,关闭策略并等待模拟资金返回主账户。
## 用法
1.放置`skill/`将目录导入到支持自定义技能的代理环境中。
2.确保代理人可以阅读`skill/SKILL.md`.
3.配置代理的 Goldstonestock API基本 URL:

```文本
CLAWSTOCK_API_BASE_URL=https://your-clawstock-api.example.com
```

4. 例如,在代理会话中发起一个与 Goldstonestock 相关的请求：

```文本
请帮我登录Goldstonestock并查看我的主账户余额。
```

## 登录流程概述
该技能要求代理使用邮箱登录,而不是请求敏感凭证：
1.用户提供邮箱地址。
2.代理程序调用`/v1/ailogin`以创建登录
3.用户收到后端发送的验证码 提供的代理程序调用`/v1/aiverylogin`以验证完成登录。
4.登录验证成功后，代理会保存返回结果api_key以供后续 API 请求使用。

已认证的 API 请求使用：

```text
Authorization: Bearer <api_key>
```
## 安全规则
SKILL.md明确要求智能体遵守以下界限：
不要请求或处理用户的私钥、登录密码。
不要承诺退款，也不要将产品描述为保本或保证盈利。
请勿提供超出用户明确要求范围的个性化财务建议。
在进行投资、存​​款、提交存款交易、关闭策略之前，代理人必须与用户确认关键参数。
主要是该工具仅仅提供模拟投资。
要退出某项策略，应先关闭该策略；资金返回主账户后。
如果 API 密钥在聊天中暴露出来，客服人员应该在密钥轮换功能可用时告知用户轮换密钥。
## 账户模型
Goldstonestock主要向用户展示一种类型的账户：
-MAIN用户的主账户。模拟资金会存入此账户，新策略的资金也会从此账户转出。
该技能要求智能体在解释余额变化、策略开始和策略结束时遵循此模型。
